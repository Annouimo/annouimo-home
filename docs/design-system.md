# Annouimo 网站共用设计规范

以 [个人主页](https://annouimo.com/) 为视觉基准。配色沿用主页，字号、间距和内容表面在三个子站的预览中校准。

## 站点与导航

| 显示名称 | 地址 | 用途 |
| --- | --- | --- |
| Annouimo | https://annouimo.com/ | 个人主页、站点入口、项目精选 |
| 博客 | https://blog.annouimo.com/ | 按分类和时间阅读文章 |
| 书与影 | https://gallery.annouimo.com/ | 浏览阅读与观看记录 |
| 求知札记 | https://learn.annouimo.com/ | 阅读讲义、操作演示 |

子站的公开页面提供一个清楚的「个人主页」入口。站点标题返回本站首页。站内导航按任务组织，保留博客分类、书与影的作品分类与搜索、求知札记的讲义目录。跨站链接使用上表名称，默认在当前标签页打开。

## 颜色与主题

以下颜色来自现有个人主页。按用途命名 CSS 变量，每个主题分别设置颜色。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面底色 | `#F5F4ED` | `#20211E` |
| 正文 | `#262824` | `#EDEDE2` |
| 次要文字 | `#595D55` | `#B8B9AD` |
| 链接与焦点 | `#1B365D` | `#ACC7EB` |
| 分隔线 | `#D8D7CB` | `#41433B` |
| 行悬停背景 | `#EDEDE3` | `#2B2D27` |

- 主题默认跟随系统。已有手动开关的站点，在各自预览中验证后再决定是否简化。
- 内容表面用于区分图表、表单或浮层，具体颜色先在实际页面上验证。
- 图表和进度状态保留各自的语义色，关键状态同时有文字、形状或线型提示。

## 文字层级与版面

- 长文和公开详情页以 **720 px** 为起点，手机两侧留 **20–24 px**。后台可使用更宽、更紧凑的操作布局，讲义图表可宽出正文。
- 优先用页标题、节标题、正文、元信息四档建立层级。正文以系统无衬线为主，标题允许自然换行。中文衬线标题先在真实长文中对照。弱化元信息时保持可读。
- 标题、正文与列表沿同一左边界。相关内容靠近，章节间留更大的间距。宽公式、表格和代码可在内容块内滚动，页面正文保持在视口内。

## 内容分组与控件

- 同类条目优先用列表组织。细线分隔行、区块和状态，边框标出需要辨认的输入区域。独立内容表面用于交互图、表单或浮层。常规卡片保持平坦，阴影用于实际覆盖页面的浮层。
- 链接负责跳转，正文内用下划线。按钮负责操作，主次由填充和边框区分。进度、保存结果等状态使用清楚的文字。键盘焦点始终可见，触屏可完成主要操作。
- 提示、标签与小标题应帮助阅读、筛选或行动。任务所需的控件按条件出现。常用内容默认可见。短评保持一行，长标题允许换行。
- 图表用清楚的轴标、单位和图注。并列数字可用等宽数字对齐。对照色同时配合标签、线型或形状，保留学科和阅读状态各自的语义。

## 站点图标

[SVG 原稿](../static/icons/) 用墨蓝底 `#1B365D` 和暖白图形 `#FAF9F5`。个人主页用衬线 A，博客用笔尖，书与影用画框，求知札记用曲线。设计和改动时，把四枚图标一起放到浅色与深色标签栏上，按 **16 × 16 px** 检查辨识度。

## 验证

在实际预览页检查长标题、正文段落、元信息、列表和图表的顺序。对照桌面、手机、浅色与深色，关注长公式或代码的溢出、键盘焦点、触摸操作和状态辨识度。三站试用后再固定字号、间距档位和共用 CSS。
