# Annouimo 网站共用设计规范

初稿。以 [个人主页](https://annouimo.com/) 为视觉基准，先用一篇博客正文和一个书与影作品详情页验证，再确定各站的具体样式。

## 站点与导航

| 显示名称 | 地址 | 用途 |
| --- | --- | --- |
| Annouimo | https://annouimo.com/ | 个人主页、站点入口、项目精选 |
| 博客 | https://blog.annouimo.com/ | 按分类和时间阅读文章 |
| 书与影 | https://gallery.annouimo.com/ | 浏览阅读与观看记录 |
| 求知札记 | https://learn.annouimo.com/ | 阅读讲义、操作演示 |

子站的公开页面提供一个清楚的「个人主页」入口。站点标题返回本站首页。站内导航按任务组织，保留博客分类、书与影的作品分类与搜索、求知札记的讲义目录。跨站链接使用上表名称，默认在当前标签页打开。

## 颜色与主题

以下颜色来自现有个人主页。按用途命名 CSS 变量，每个主题分别设置颜色。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面底色 | `#F5F4ED` | `#20211E` |
| 正文 | `#262824` | `#EDEDE2` |
| 次要文字 | `#595D55` | `#B8B9AD` |
| 链接与焦点 | `#1B365D` | `#ACC7EB` |
| 分隔线 | `#D8D7CB` | `#41433B` |
| 行悬停背景 | `#EDEDE3` | `#2B2D27` |

- 主题默认跟随系统。已有手动开关的站点，在各自预览中验证后再决定是否简化。
- 内容表面用于区分图表、表单或浮层，具体颜色先在实际页面上验证。
- 图表和进度状态保留各自的语义色，关键状态同时有文字、形状或线型提示。

## 版式与控件

- 长文和公开详情页以 **720 px** 为起点，手机两侧留 **20–24 px**。管理员界面可以用更宽的栏和更紧凑的间距，讲义中的图表可以超出正文栏。
- 正文优先使用系统无衬线字体。个人主页的品牌字样保持衬线。中文衬线标题先在真实文章中和无衬线标题对照。
- 短目录和项目列表优先用留白和细分隔线组织。正文内链接用下划线，键盘焦点有清晰轮廓，触屏可以完成主要操作。

## 站点图标

[SVG 原稿](../static/icons/) 用墨蓝底 `#1B365D` 和暖白图形 `#FAF9F5`。个人主页用衬线 A，博客用笔尖，书与影用画框，求知札记用曲线。设计和改动时，把四枚图标一起放到浅色与深色标签栏上，按 **16 × 16 px** 检查辨识度。

## 首轮验证

在同一篇博客正文上检查标题层级、中文段落与链接，在同一个书与影作品详情页上检查元信息、进度图和密集内容。对照桌面、手机、浅色与深色，检查键盘焦点和触屏操作。确认版式和配色后，再决定哪些 CSS 值值得提取到共用文件。
